# Contribuindo com o Crypto Guard

Obrigado pelo interesse no projeto.

## Estado atual das contribuições de código

Enquanto o Crypto Guard permanecer `UNLICENSED`, a Solucionx prioriza **Issues, relatórios de bugs, revisão técnica e relatórios privados de segurança**. Pull Requests externos com código podem ser fechados sem merge até que uma política/licença de contribuição seja definida, evitando ambiguidade sobre direitos autorais.

## Bugs

Abra uma Issue usando o template de bug. Remova caminhos pessoais, arquivos privados, senhas, tokens e outros dados sensíveis.

## Segurança

Não abra Issue para vulnerabilidades exploráveis. Siga `SECURITY.md` e use GitHub Security Advisories para comunicação privada.

## Mudanças mantidas pela Solucionx

Mudanças internas devem passar por branch/PR, checks automáticos e revisão especial quando afetarem criptografia, parsing de `.cguard`, IPC, UAC, update, build/release ou GitHub Actions.
