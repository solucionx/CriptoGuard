# Código de Conduta

Este projeto busca colaboração técnica respeitosa, objetiva e segura. Não são aceitos assédio, ameaças, publicação de dados pessoais, divulgação irresponsável de vulnerabilidades ou envio de segredos/dados privados de terceiros.

Discussões técnicas devem focar no comportamento observável, riscos, evidências e possíveis correções. Vulnerabilidades exploráveis devem seguir o canal privado descrito em `SECURITY.md`.
